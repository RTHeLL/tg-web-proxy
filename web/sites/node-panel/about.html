About our infrastructure

Node Panel operates bare-metal hosts in Frankfurt, Amsterdam, and London with AMD EPYC processors and enterprise NVMe storage. Virtual machines run on KVM with virtio drivers and live migration between racks in the same region.

We built the control panel for teams who outgrew shared hosting but did not want the complexity of hyperscaler IAM. Every resource — VMs, volumes, floating IPs, firewall groups — is addressable through the same REST API the web UI uses.

Provisioning flow

  • 01 Choose region, plan, and base image in the panel or via CLI
  • 02 Cloud-init runs on first boot; SSH keys injected automatically
  • 03 Instance receives public IPv4 and optional private VLAN address
  • 04 Snapshots and firewall rules attach without reboot when possible

Compliance & peering

Datacenters hold ISO 27001 certification. Customer data stays in the selected region unless you configure cross-region replication. We peer with major European transit providers and publish monthly latency matrices on request.

Node Panel is not a CDN, managed Kubernetes provider, or domain registrar. We focus on reliable compute and leave application orchestration to your toolchain of choice.
