# Каталог камуфляжных сайтов

Каждая папка — самодостаточный статический сайт для `--site-dir` / Docker `--site`.

| ID | Тема | Стиль |
|---|---|---|
| `northwind-field` | Полевые заметки, картография | Светлый, морской, serif |
| `studio-garden` | Ландшафтная студия | Зелёный, минимализм |
| `atlas-books` | Независимый книжный | Тёплый, «бумажный» |
| `harbor-dental` | Стоматология | Медицинский, чистый |
| `craft-roastery` | Обжарка кофе | Тёмный, craft |
| `pixel-repair` | Ремонт техники | Техничный, контрастный |

Список: `./scripts/list-sites.sh`

Перед продом замените тексты и визуал на **уникальный** контент оператора.
