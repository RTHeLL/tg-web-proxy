# Сайты для `--site`

Каждая папка — отдельный статический сайт. Подключается в установщике или через `--site-dir` в `deploy/install.sh`.

| id | о чём |
|---|---|
| `northwind-field` | полевые заметки |
| `studio-garden` | ландшафт |
| `atlas-books` | книжный |
| `harbor-dental` | стоматология |
| `craft-roastery` | обжарка |
| `pixel-repair` | ремонт техники |

Список: `bash scripts/list-sites.sh`

Перед боем лучше переписать тексты под себя — одинаковые шаблоны у разных хостов палятся.
